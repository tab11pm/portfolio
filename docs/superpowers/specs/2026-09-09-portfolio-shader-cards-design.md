# Анимированные shader-карточки портфолио: дизайн

**Дата:** 2026-09-09
**Статус:** согласовано, ожидает проверки спецификации пользователем

## Цель

Добавить на маршрут `/portfolio` анимированные WebGL shader-фоны из предоставленного компонента `feature-shader-cards.tsx`, не меняя утверждённый состав портфолио и публичное содержание карточек.

## Границы

Входят:

- четыре существующие карточки: Nadim, PinShop TJ, Moodle Math MCP и SDO MCP;
- непрерывная фоновая анимация `Warp` для каждой карточки;
- адаптивная сетка с одной, двумя или тремя колонками;
- установка `@paper-design/shaders-react`;
- компонент в `/components/ui/feature-shader-cards.tsx`.

Не входят:

- новые карточки или проекты;
- hover-, click- и entrance-анимации карточек;
- изменения текста, технологий, ссылок или порядка проектов;
- отдельная generic-feature секция из шести элементов.

## Структура и поток данных

`app/portfolio/page.tsx` передаёт утверждённый список `projects` из `data/projects.ts` компоненту `FeaturesCards` из `/components/ui/feature-shader-cards.tsx`.

`FeaturesCards` остаётся клиентским компонентом, потому что `Warp` использует WebGL. Он отображает одну карточку на каждый входной проект. Для четырёх карточек последовательно применяются первые четыре конфигурации из исходного промпта: параметры `proportion`, `softness`, `distortion`, `swirl`, `swirlIterations`, `shape`, `shapeScale`, палитра и `speed={0.8}`. У второй и четвёртой карточек `dots` заменяется на `stripes`: установленная версия библиотеки не поддерживает `dots`, а замена сохраняет всю shader-анимацию и меняет только рисунок паттерна. Анимация запускается самим `Warp` постоянно; дополнительное движение карточек не добавляется.

`Warp` занимает весь фон контейнера с радиусом скругления. Поверх него расположен непрозрачно читаемый тёмный контентный слой: номер, категория, название, описание, стек и условная внешняя ссылка. Внешняя ссылка рендерится только при наличии `href`: это сохраняет отсутствие ссылки у Nadim и PinShop TJ.

## Стили и устойчивость

Проект уже использует TypeScript и Tailwind CSS. Папка `/components/ui` создаётся для изолированных, переиспользуемых UI-компонентов и совместимого с shadcn пути импорта; полноценные shadcn-примитивы для этой задачи не требуются.

Карточки сохраняют текущие breakpoints: одна колонка на мобильном экране, две на среднем и три на широком. Тёмный слой гарантирует доступность текста независимо от кадра shader-анимации. При отсутствии WebGL либо при ошибке отрисовки пользователь по-прежнему видит контент карточки на тёмном фоне; анимация не является носителем информации.

## Проверка

- `npm install @paper-design/shaders-react` обновляет манифест и lockfile;
- `npm run test` подтверждает разрешённый набор из четырёх проектов и условные ссылки;
- `npm run lint` и `npm run build` проходят успешно;
- ручной smoke-check `/portfolio` на desktop и mobile подтверждает четыре видимых shader-карточки, читаемость контента, ссылку только у двух MCP-проектов и отсутствие ссылки у PinShop TJ.

## Критерии готовности

1. `/portfolio` показывает ровно четыре утверждённые карточки проектов.
2. Каждая карточка имеет свой непрерывно анимируемый `Warp`-фон из исходного промпта.
3. Карточки не получают неоговорённых hover-, click- или entrance-анимаций.
4. Содержание, порядок и правила внешних ссылок сохранены.
5. Проверки TypeScript, ESLint, тестов и production-сборки проходят.
