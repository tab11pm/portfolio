# Сайт-визитка: дизайн

**Дата:** 2026-09-09  
**Статус:** согласовано, ожидает просмотра спецификации перед планированием

## Цель

Создать русскоязычный персональный сайт-визитку на Next.js с тремя обязательными страницами: главной, резюме и портфолио. Сайт должен кратко и профессионально представить Табреза Шонизорова, его подтверждённый опыт, образование и отобранные работы; развёртывание выполняется на Vercel.

## Границы

Входят в работу:

- адаптивный сайт с маршрутами `/`, `/resume`, `/portfolio`;
- общий тёмный редакторский визуальный язык Midnight Editorial;
- данные и изображения из `/mnt/D/tusur/веб/лабы/portfolio` и `/mnt/D/life/portfolio`, после актуализации публичных формулировок;
- фоновые canvas/SVG-эффекты и reveal-анимации, адаптированные из `/mnt/D/life/portfolio`;
- метаданные, доступность, проверка сборки и Vercel-ready конфигурация.

Не входят:

- серверная часть, CMS, форма с хранением заявок, авторизация;
- англоязычная версия;
- публикация исключённых проектов: Smart Marketplace, Black Grill и Telegram MCP;
- внешняя ссылка в карточке PinShop TJ.

## Визуальная система

Выбран стиль **Midnight Editorial**:

- глубокий тёмный фон, мягкие фиолетовые акценты и высокая контрастность текста;
- крупные редакторские заголовки, нейтральный гротеск для интерфейса и моноширинный шрифт для технических меток;
- тонкие линии, модульная сетка, асимметричный воздух и минимум декоративного шума;
- авторские градиентные обложки/иллюстрации для героя и каждой карточки проекта;
- единый набор тонких линейных иконок для навыков, контактов и внешних переходов.

На главной: абстрактная монограмма/иллюстрация, крупное позиционирование, CTA и компактные метки опыта, ТУСУР и стека.  
На резюме: вертикальная временная линия, блоки опыта и стековые бейджи.  
На портфолио: сетка из четырёх выразительных карточек с цветовыми обложками, описанием роли/технологий и ссылками только там, где они разрешены.

## Анимация и производительность

Из `/mnt/D/life/portfolio` переносятся и адаптируются:

- `PixelCanvas` — приглушённый пиксельный фон для героя;
- `DotMatrix` — спокойная реактивная сетка для резюме;
- `WarpField` и/или `FloatingPaths` — фон для портфолио и связующих секций;
- `useReveal` — одноразовое появление секций во время прокрутки;
- `backdrop` — общий бюджет кадров: одновременно работает максимум один тяжёлый canvas-фон, эффекты прекращаются за пределами экрана и в скрытой вкладке.

Все эффекты декоративны. Контент не зависит от JavaScript. При `prefers-reduced-motion: reduce` canvas-фоны отображаются статично, CSS-анимации отключаются, а секции сразу видимы.

## Техническое решение

- Next.js с App Router и TypeScript;
- статические маршруты без базы данных и API;
- отдельные типизированные модули данных для профиля, опыта, навыков, проектов и контактов;
- переиспользуемые компоненты: `Header`, `Footer`, `PageHero`, `Section`, `ProjectCard`, `Timeline`, `SkillList`, `ContactLinks`;
- `next/image` для локальных растровых материалов, SVG/CSS для декоративной графики;
- метаданные для каждой страницы, favicon, sitemap и понятные заголовки;
- конфигурация, совместимая с Vercel: production-сборка не требует собственного сервера или секретов.

## Проверка

- TypeScript без ошибок;
- ESLint без ошибок;
- `next build` успешно создаёт production-сборку;
- автоматическая или ручная проверка `/`, `/resume`, `/portfolio` на desktop и mobile;
- проверка активной навигации, внешних ссылок MCP-репозиториев, отсутствия ссылки у PinShop TJ и отсутствия исключённых проектов;
- проверка keyboard-навигации, заметного focus state, alt-текстов, семантических заголовков и `prefers-reduced-motion`;
- Vercel Preview используется как финальная проверка опубликованной сборки.

## Критерии готовности

1. На Vercel опубликован русскоязычный сайт с тремя доступными маршрутами.
2. Главная, резюме и портфолио используют согласованную Midnight Editorial систему.
3. Публичный опыт начинается с 2024 года; в тексте нет периода 2021–2023 и неподтверждённых утверждений о PinShop TJ.
4. Портфолио содержит только Nadim, PinShop TJ, Moodle Math MCP и SDO MCP.
5. PinShop TJ не имеет внешней кнопки; оба MCP-проекта ведут на согласованные GitHub-репозитории.
6. Фоновые эффекты не мешают чтению, уважает reduced motion и не запускают одновременно несколько тяжёлых анимаций.
