# Главная: Minimalist Hero

**Дата:** 2026-09-09  
**Статус:** согласовано, ожидает ревью спецификации перед планированием

## Цель

Заменить текущий hero главной страницы портфолио на адаптированную композицию Minimalist Hero: навигация, трёхколоночный hero с портретом, крупным позиционированием, CTA и контактами. Сохраняются визуальная палитра и типографика существующего сайта Midnight Editorial; жёлтый цвет из исходного примера не используется.

## Архитектура

`MinimalistHero` получает все текстовые данные, маршруты, источник и alt-текст портрета, контакты и локацию через типизированные props. `app/page.tsx` остаётся владельцем конкретного контента главной и передаёт компоненту утверждённые данные. Компонент является client component, поскольку анимации выполняются Framer Motion.

Главная использует собственные header и footer внутри hero, поэтому общий `Header` и `Footer` не должны отображаться на `/`. Они продолжают обслуживать `/resume` и `/portfolio`. Механизм исключения не должен влиять на семантику `<main>` или доступность остальных маршрутов.

## Визуальное и адаптивное поведение

На desktop hero занимает высоту экрана и состоит из трёх колонок: слева — краткое описание и CTA, по центру — портрет с акцентным круглым фоном, справа — крупный заголовок. Сверху отображаются инициалы и навигация; снизу — контакты и локация. Портрет сохраняет профильный кадр, корректный alt-текст и не должен быть обрезан по лицу.

На ширинах mobile секции идут в последовательности: фото, описание, заголовок, контакты. Ссылки навигации заменяет функциональная кнопка меню, доступная с клавиатуры. В `prefers-reduced-motion: reduce` все motion-анимации отсутствуют, а контент сразу доступен.

## Технические соглашения

- Компоненты располагаются в существующей папке `components/ui`; глобальные стили остаются в `app/globals.css`.
- Tailwind CSS и TypeScript уже настроены. `lucide-react` уже установлен; добавляется только `framer-motion`.
- Для совместимости с API компонента добавляется `lib/utils.ts` с `cn`.
- Портрет хранится в репозитории и рендерится через `next/image`; при ошибке загрузки вместо него остаётся нейтральная CSS-заглушка, без зависимости от сторонних сервисов.
- Цвета берутся из текущих CSS-переменных сайта, без `bg-yellow-*` и других цветов исходного примера.
